# IA4Sustainability

IA4Sustainability ayuda a organizar información y decisiones de sostenibilidad relacionadas con las Normas Europeas de Información sobre Sostenibilidad (ESRS). Está orientada a equipos que necesitan describir una organización, revisar temas propuestos, registrar decisiones humanas de materialidad y preparar una lista de información disponible y pendiente.

No genera automáticamente una memoria ESG o ESRS completa, final ni garantizada. Las salidas actuales son apoyo de trabajo: propuestas revisables, hoja de decisión, listas CSV, resumen de preparación y cobertura, paquete HTML resumido, documento DOCX guiado y, bajo condiciones técnicas, un candidato XHTML/iXBRL. Ninguna salida sustituye aseguramiento, opinión legal, presentación oficial ni aceptación regulatoria.

## Qué necesitas preparar

- Datos básicos de la organización, actividad, ejercicio, tamaño y alcance.
- Personas internas que puedan revisar impactos, riesgos, oportunidades y evidencias.
- Criterio humano para confirmar temas materiales y decidir aplicabilidad.
- Información y referencias de evidencia cuando se completen respuestas.

## Recorrido

1. Describir la organización.
2. Revisar temas candidatos propuestos por la aplicación.
3. Realizar y documentar la doble materialidad con el equipo responsable.
4. Confirmar temas materiales y motivos que se quieran registrar.
5. Reunir información, marcar pendientes y justificar no aplicables.
6. Consultar el resumen de preparación y descargar salidas disponibles.

## Probar en local

**Aviso antes de arrancar:** el perfil local incluido recrea su base SQLite al iniciar el componente web. Usa solo datos ficticios. No lo uses para información real ni para conservar trabajo.
