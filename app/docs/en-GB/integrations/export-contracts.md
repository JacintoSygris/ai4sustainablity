# Export Contracts

Back to the [documentation index](../index.md).

Each output has its own content and scope.

## Preparation Summary JSON

Contains section status, downloads, next actions, limitations, topics and counters. It is not a report.

## HTML Package

Contains a printable summary of identification, confirmed topics, coverage and limits. It does not contain a developed ESRS report.

## CSV

CSV files support review of the information list and recorded responses. They may contain technical identifiers required for integrations.

## Guided DOCX

The DOCX document provides structure, guidance and spaces to complete. It does not automatically transfer all information into a final report and does not replace editorial review.

## XHTML/iXBRL Candidate

This is a technical operation conditional on structured data, taxonomy assets and validation. It does not imply official submission, assurance, legal opinion or regulatory acceptance.
