# Information Contract

Back to the [documentation index](../index.md).

This contract describes how to interpret the information list and responses from an integration.

## Selection

The application starts from cross-cutting ESRS information and adds topical information when configuration can link confirmed topics to Disclosure Requirements. If the mapping is missing, invalid or partial, scoping mode must be displayed clearly.

## Responses

Responses may be pending, completed, marked not applicable with justification or invalid for format reasons. A completed response contains structured values and references where required; it does not certify material truth.

## Evidence

The evidence reference is a traceability field. An integration must not show it as a validated document, sufficient proof or assurance.

## Counters

Counters should publish numerator and denominator where possible. If they include justified non-applicable items, this must be stated to avoid interpretation as a percentage of information gathered.
