# Describe The Organisation

Back to the [documentation index](../index.md).

The first task is to record a profile sufficient for the application to propose topics and organise information. Use fictitious data in the included local installation, because its database is recreated when the web component starts.

## Usual Information

- organisation name;
- reporting year;
- headquarters country and currency;
- activity, products and services;
- approximate size, workforce and turnover;
- subsidiaries, countries or relevant regions;
- legal form and listed status where relevant;
- CNAE/NACE activity code if known.

## What This Information Proves

It proves that the user has recorded a starting profile. It does not prove that the corporate scope is correct, that all activities are included or that the organisation is required to report under CSRD.

## Usage Recommendations

Review the fields before moving to topic proposals. If you work with a group, document outside the application how the boundary was decided. If data is missing, use prudent notes and update them before using outputs in real work.
