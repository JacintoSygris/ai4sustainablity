# Describe The Organisation

Back to the [documentation index](../index.md).

The first task is to record a profile sufficient to characterise the organisation within ESG work (environmental, social and governance; ASG in Spanish) and the CSRD/ESRS framework. That characterisation allows the application to recommend candidate matters for double materiality assessment and then organise Disclosure Requirements, indicators/data and evidence. Use fictitious data in the included local installation, because its database is recreated when the web component starts.

## Usual Information

- organisation name;
- reporting year;
- headquarters country and currency;
- activity, products and services;
- approximate size, workforce and turnover;
- subsidiaries, countries or relevant regions;
- legal form and listed status where relevant;
- CNAE/NACE activity code if known.

## What This Information Proves

It proves that the user has recorded a starting profile. It does not prove that the corporate scope is correct, that all activities are included, that the ESG analysis is complete or that the organisation is required to report under CSRD.

## Usage Recommendations

Review the fields before moving to candidate matter proposals. If you work with a group, document outside the application how the boundary was decided. If data is missing, use prudent notes and update them before using outputs in real work.
