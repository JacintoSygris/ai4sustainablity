# Contratos de exportación

Volver al [índice de documentación](../index.md).

Cada salida tiene contenido y alcance propios.

## Resumen de preparación JSON

Contiene estado de secciones, descargas, siguientes acciones, limitaciones, temas y contadores. No es un informe.

## Paquete HTML

Contiene un resumen imprimible de identificación, temas confirmados, cobertura y límites. No contiene un informe ESRS desarrollado.

## CSV

Los CSV sirven para revisar la lista de información y las respuestas registradas. Pueden contener identificadores técnicos necesarios para integraciones.

## DOCX guiado

El documento DOCX ofrece estructura, orientaciones y espacios para completar. No traslada automáticamente toda la información a una memoria final ni sustituye revisión editorial.

## Candidato XHTML/iXBRL

Es una operación técnica condicionada a datos estructurados, activos de taxonomía y validación. No implica presentación oficial, aseguramiento, opinión legal ni aceptación regulatoria.
