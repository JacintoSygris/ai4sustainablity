# Contrato de información

Volver al [índice de documentación](../index.md).

Este contrato describe cómo interpretar la lista de información y las respuestas desde una integración.

## Selección

La aplicación parte de información transversal ESRS y añade información temática cuando la configuración permite relacionar temas confirmados con requisitos de divulgación. Si la correspondencia falta, es inválida o parcial, el modo alcance debe mostrarse claramente.

## Respuestas

Las respuestas pueden estar pendientes, completadas, marcadas como no aplicables con justificación o inválidas por formato. Una respuesta completada contiene valores estructurados y referencias cuando se exigen; no acredita verdad material.

## Evidencia

La referencia de evidencia es un campo de trazabilidad. Una integración no debe mostrarla como documento validado, prueba suficiente ni aseguramiento.

## Contadores

Los contadores deben publicar numerador y denominador cuando sea posible. Si incluyen no aplicables justificados, debe indicarse para evitar interpretaciones como porcentaje de información reunida.
