# Motor de aprendizaje opcional

Cualificación técnica sintética local del árbol público fechada el 2026-10-05: 96 pruebas de aprendizaje opcional y 498/498 pruebas Node, sin omisiones Node. La suite PHP completa registra 1.941 casos: 1.935 correctos, un fallo de tiempo y cinco omisiones. La repetición secuencial del caso fallido pasó la aserción original <6s (1 caso, 5 aserciones); el fallo completo se conserva y no demuestra concurrencia. Las cinco omisiones requieren cualificación separada en plataformas nativas. Typecheck, lint y build pasaron antes de esta actualización documental; no se afirma una nueva ejecución. Esta cualificación previa a publicación no acredita activación empresarial, calidad del modelo ni despliegue.

El código opcional WP13 registra etiquetas de temas revisadas, relevancia de datos y selección para contestar como decisiones independientes, revisiones de origen, generaciones de autorización y recibos de cierre. Lo no revisado permanece sin observar; una etiqueta ausente no se convierte en un negativo. La revisión P9 no elimina obligaciones normativas. Entradas obsoletas, revocaciones y eliminación de cuentas invalidan la elegibilidad y los candidatos dependientes.

La API autenticada ofrece `GET/PUT /api/learning-case/draft` y `POST /api/learning-case/close` y `/withdraw`. Los paneles conservan los límites de sesión y CSRF existentes. El cierre es un mecanismo sintético deshabilitado por defecto; la autoridad se enlaza a `DenyLearningAuthorizationAuthority`. No existe un emisor operativo positivo en este paquete. No usar `APP_ENV=testing` para habilitar uso empresarial.

Los módulos Python opcionales son independientes de `public_runtime`, `public_model_app.py`, los requisitos de servicio y los modelos existentes. El servicio público permanece sin cambios. La inferencia offline utiliza `learning_visible_filter.py`: positivos crudos, umbrales por etiqueta, exclusión de resúmenes y claves no candidatas y orden estable por puntuación. El adaptador omite cabezas de aprendizaje desconocidas; este límite rechaza objetos de políticas sectoriales y CRC. No se incluyen paquetes privados de servicio, candidatos entrenados, corpus ni JSON de políticas.

Instalar `ai-service/requirements-learning.txt` solo en un entorno opcional separado; conservar `requirements.public.txt` para el servicio existente. El lockfile de aprendizaje es una entrada de origen con versiones y procedencia fijadas. Las dependencias opcionales se instalaron en entornos locales aislados; esto no acredita instalación pública de producción ni aceptación de licencias u obligaciones transitivas. Véase el [inventario de dependencias](learning-dependencies.md).

La cualificación local comprende comprobaciones sintéticas de Python, Laravel y frontend; no sustituye las verificaciones operativas del entorno del operador. Desde `app/ai-service`, usar `PYTHONPATH=src` para aprendizaje. El arnés nativo requiere autorización explícita: desde `app/web`, `php tests/scripts/t11-native.php --allow-native-fixture --profile=<perfil-desechable-del-operador> --engines=mysql,pgsql --require-positive-discovery`. Se conservan los controles de driver, versión, loopback y base de datos. Las pruebas portables utilizan entradas sintéticas, sin leer recibos privados ni configuración nativa ignorada. Los casos nativos se omiten sin entradas explícitas; una omisión no acredita cualificación.

Se excluyen los arneses de navegador y HTTP ligados a una máquina. El paquete público carece del arnés E2E privado y sus 96 pruebas de aprendizaje no heredan esa prueba. Las revisiones acotadas de componentes y validación simulada cualifican solo sus aspectos; no aprueban toda la versión, Arelle real ni derechos. Los pilotos reales siguen ABIERTOS hasta aprobar derechos exactos, política y seguridad y disponer de un emisor operativo. No se autoriza implícitamente acceso SQL/Mongo directo. La publicación y el despliegue requieren comprobación efectiva del remoto y del entorno desplegado. Jenkins y el despliegue público pertenecen al operador usuario; no se registra una nueva publicación, ejecución de Jenkins, activación ni despliegue.
