# Revisar asuntos propuestos

Volver al [índice de documentación](../index.md).

La aplicación puede proponer asuntos ASG a partir del perfil de la organización para iniciar el análisis de doble materialidad conforme a ESRS. Esas propuestas son automáticas y sirven como punto de partida para la revisión humana.

## Qué contiene la propuesta

La propuesta conecta datos de caracterización con claves internas del modelo y con el catálogo de asuntos ESRS configurado. Puede incluir asuntos de revisión, asuntos agregados o claves que no se convierten automáticamente en un asunto final.

## Qué no significa

Una propuesta no significa que el asunto sea material. Una ausencia de propuesta tampoco significa que el asunto sea irrelevante. La decisión exige revisar impactos, riesgos, oportunidades, contexto, evidencias y criterio profesional dentro del análisis de doble materialidad.

## Cómo revisarla

Contrasta cada asunto con actividad real, ubicaciones, cadena de valor, personas afectadas y dependencias financieras. Añade o retira asuntos cuando el análisis lo justifique. Conserva una explicación de los cambios importantes, especialmente si se descarta un asunto sensible o esperado por el contexto.
