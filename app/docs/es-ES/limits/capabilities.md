# Límites de capacidad

Volver al [índice de documentación](../index.md).

## Disponible

- Registrar perfil de organización.
- Obtener y revisar asuntos ASG candidatos para el análisis de doble materialidad.
- Guardar decisiones humanas de materialidad.
- Usar una guía de trabajo para doble materialidad.
- Inventariar requisitos de divulgación, indicadores/datos ESRS, respuestas, pendientes y no aplicables.
- Descargar CSV, JSON y resumen HTML cuando el estado lo permite.
- Generar documentos guiados y ciertas salidas técnicas cuando sus dependencias están disponibles.

## Condicionado

- La lista temática de información depende de correspondencias configuradas y válidas.
- El candidato XHTML/iXBRL exige datos estructurados suficientes, validación técnica en ejecución y aprobación humana para cualquier uso posterior.
- Las funciones documentales están desactivadas en el perfil público incluido y no se suministra el servicio de extracción compatible.
- El correo, OAuth, colas, almacenamiento persistente y controles externos dependen del operador.

## No ofrecido

- Memoria ESRS completa, final o garantizada.
- Garantía de cumplimiento, precisión o aceptación regulatoria.
- Aseguramiento, auditoría, opinión legal o aprobación metodológica.
- Realización automática o confirmación autónoma del análisis de doble materialidad.
- Verificación independiente de evidencias.
- Conservación de datos en el perfil local incluido.
- Presentación oficial ante autoridades.

Cada operador debe revisar el alcance real de su instalación antes de usarla con información empresarial.
