# Inventario ESRS IG 3

Referencia vigente:

- [Information contract](../../docs/en-GB/integrations/information-contract.md)

El inventario ayuda a organizar información. Sin una correspondencia completa, valida y configurada entre temas y requisitos de divulgación, la aplicación debe explicar el modo alcance y no presentar la lista temática cómo completa.
