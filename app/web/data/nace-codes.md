# Catálogo CNAE/NACE

Referencia vigente:

- [Correspondencias y catálogos](../../docs/es-ES/integrations/mappings-and-catalogues.md)
- [Mappings and catalogues](../../docs/en-GB/integrations/mappings-and-catalogues.md)

El catálogo usado procede de una estructura CNAE 2025 en español. Cuando un campo inglés conserva título español, debe tratarse como dato pendiente de localización, no como traducción inglesa completa.
